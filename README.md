# How-to Documentation

Records of how tools and systems have been configured, kept for future reference. Each guide is written for competent users who are not specialists in the operating-system details, or who return to the subject infrequently.

## Guides

| Guide | Covers |
|---|---|
| [Monitor Input Switching](Monitor_Input_Switching_Setup_Guide.md) | Switching a BenQ RD320U monitor and its built-in KVM between an Arch Linux (Hyprland) PC and a Windows 10 laptop with a keyboard shortcut, using DDC/CI |
| [SSH Key Access](SSH_Key_Access_Setup_Guide.md) | Key-only SSH and scp access from a Windows 10 laptop and Arch Linux under WSL 2 to an Arch Linux PC, with host aliases and SSH agents on both clients |

## Conventions

- Each guide follows the same structure: Hardware and Context, Tested With, How It Works, a section per platform, Troubleshooting Notes, Pitfalls (where relevant), Quick Reference, Sources.
- Serial numbers, user names and other identifying details are replaced with placeholders such as `<MONITOR_SERIAL>`.
